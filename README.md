<h2> About Me</h2>


· 🎓 Software Developer transitioning into QA Automation Engineer.

· 🧪 Focused on UI & API test automation with Selenium, Playwright, Cypress, Karate DSL & Postman.

· 💻 Experience building and testing web and REST API applications using Java, C#, .NET & Spring Boot.

· 📊 Learning to design stable regression suites, integrate tests into CI/CD pipelines (Git, GitLab CI/Jenkins) and report with Allure/JUnit.

· 🧠 Constant learner, currently deepening my knowledge in testing strategies, ISTQB fundamentals and basic performance testing with JMeter.

· 🤝 I enjoy collaborating in agile teams, turning requirements into reliable, maintainable test cases.

· 🚀 Motivated to grow as a QA Automation Engineer and contribute to high-quality, robust software.
